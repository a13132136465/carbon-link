# CarbonLink 项目功能说明与操作手册

> 文档依据当前仓库代码编写，功能状态截至 2026-09-28。本文所称“已实现”是指仓库中已有对应前端、API 或数据模型；已知边界与尚未完成的部分见文末。

## 1. 项目简介

CarbonLink 是一个碳项目登记、核证、碳额度签发、持仓管理、市场交易和永久注销平台。系统以 PostgreSQL 中的业务账本为事实来源，关键业务操作可以写入链上任务队列，后续由 EVM/Avalanche 适配器完成存证。

项目主要由以下部分组成：

- React + TypeScript 管理控制台；
- FastAPI 业务 API；
- PostgreSQL 数据库与 Alembic 迁移；
- Solidity 智能合约，包括项目登记 ERC-721 合约和碳额度 ERC-1155 合约；
- Docker Compose 本地或服务器部署配置；
- 覆盖项目、交易、注销主流程的自动化测试。

## 2. 当前已实现功能

### 2.1 账号、登录与权限

- 邮箱和密码登录，登录成功后签发 JWT；
- 密码使用 Argon2 哈希保存；
- 支持管理员、核证员、企业用户三种角色；
- 支持通过 API 注册普通企业用户；
- 登录页支持企业用户自助注册；
- 管理员可查看用户、分配角色并启停账号；
- 用户可修改密码，并可通过邮件令牌找回密码；
- 应用首次启动时可根据环境变量自动创建初始管理员；
- 登录过期或认证失败时，控制台会清除本地令牌并返回登录页。

### 2.2 运营总览

登录后可查看平台级运营数据：

- 累计签发量；
- 累计注销量和注销率；
- 当前市场在售量；
- 累计成交量；
- 已登记项目数；
- 最近登记项目及其状态；
- 最新市场挂单和挂牌价格。

### 2.3 碳项目管理

- 所有登录用户均可新建项目；
- 项目信息包括名称、类型、地区、方法学、预计减排量和项目说明；
- 项目所有人可将草稿或已驳回项目重新提交审核；
- 项目所有人可编辑或删除草稿、已驳回项目；
- 管理员和核证员可审核待审核项目，选择通过或驳回并填写审核意见；
- 支持按草稿、待审核、已通过、已驳回筛选；
- 项目状态流转为：

```text
草稿 draft ──提交──> 待审核 pending ──通过──> 已通过 approved
                                 └──驳回──> 已驳回 rejected ──重新提交──> 待审核
```

### 2.4 碳额度签发与批次管理

- 管理员和核证员可对已通过项目签发碳额度；
- 签发时指定核证年份和数量，数量精度支持 4 位小数；
- 同一项目、同一核证年份只能存在一个签发批次；
- 系统自动生成唯一批次序列前缀；
- 签发额度直接进入项目所有人的持仓；
- 签发接口使用 `Idempotency-Key` 防止重复提交。

### 2.5 我的资产与账本

- 查看本人各批次的资产总量、可用余额和挂单锁定数量；
- 查看批次核证年份、方法学和批次编号；
- 一键复制批次编号；
- 查看额度签发、市场买入、市场卖出和永久注销流水；
- 每笔流水保存变动数量、变动后余额、关联业务和时间；
- 数据库约束防止负余额以及锁定数量超过持仓数量。

### 2.6 碳额度交易市场

- 持有可用额度的用户可发布 CNY 计价的限价卖单；
- 发布挂单后，相应数量从可用余额转为锁定余额；
- 可按批次编号搜索当前在售挂单；
- 买方可购买全部或部分挂单，支持部分成交；
- 卖方不能购买自己的挂单；
- 挂单全部成交后自动变为已成交状态；
- 卖方可撤销自己的未完成挂单，管理员也可通过 API 撤销；
- 撤单后剩余锁定数量自动释放；
- 成交时在同一数据库事务中更新买卖双方余额、挂单、成交记录和双方流水；
- 用户可查看自己的买入、卖出和成交金额记录；
- 购买接口使用 `Idempotency-Key` 防止重复成交。

### 2.7 永久注销与证书

- 用户可将本人未锁定的碳额度永久注销；
- 注销时记录资产批次、数量、受益方和注销用途；
- 注销成功后生成唯一证书编号；
- 用户可查看自己的历史注销证书；
- 可使用证书编号验证证书信息；
- 证书查询 API 无需登录，可用于公开核验；
- 控制台提供无需登录的 `/verify` 公开证书核验页；
- 注销接口使用 `Idempotency-Key` 防止重复注销；
- 注销不可撤销，相应额度会永久退出可流通余额。

### 2.8 审计日志

系统会记录用户注册、项目创建和提交、项目审核、额度签发、挂单创建和撤销、交易结算、额度注销等关键事件。管理员可在“审计日志”页面按操作名称或资源编号搜索最近记录。

### 2.9 链上存证与智能合约

- 当前环境已连接 Avalanche Fuji（Chain ID `43113`）；
- 项目登记合约：`0x590FcD85a12B9D6B00E6a38A3A72c84Ec08303c2`；
- 碳额度账本合约：`0xD979f63A0EC1540c5a551304f120bAa82CdaCe1D`；
- 可通过环境变量启用或关闭链上功能；
- 管理员可查看网络、Chain ID、确认数、签名模式、合约地址和操作账户；
- 项目审核通过、额度签发、额度注销时，可在同一业务事务中创建链上 Outbox 任务；
- 独立 Worker 会自动签名、持久化原始交易、广播、监听确认数并退避重试；
- 管理员可查看任务类型、业务资源、状态、尝试次数、交易哈希和创建时间；
- 配置接口不会返回操作账户私钥；
- 已提供项目登记、碳额度发行/转移/冻结/注销智能合约及部署脚本和合约测试。

### 2.10 运行与安全基础设施

- PostgreSQL 持久化存储；
- Alembic 数据库迁移，容器启动时自动升级结构；
- API 存活和就绪健康检查；
- 前端 Nginx 同域代理 `/api`，浏览器无需单独配置 API 地址；
- 容器以最小权限运行，Compose 默认只绑定宿主机回环地址；
- 提供 Docker 镜像测试方式和 Ubuntu 部署指南；
- 支持跨域白名单、JWT 有效期和日志级别配置。

## 4. 快速启动

### 4.1 环境要求

- 已安装 Docker Engine 或 Docker Desktop；
- 已安装 Docker Compose 插件；
- 本机端口 `3000` 和 `8000` 可用，或在 `.env` 中改为其他端口。

### 4.2 准备配置

在项目根目录复制环境变量模板：

```powershell
Copy-Item .env.example .env
```

至少修改以下配置：

```dotenv
POSTGRES_PASSWORD=强数据库密码
JWT_SECRET=至少32字符的随机字符串
BOOTSTRAP_ADMIN_EMAIL=管理员邮箱
BOOTSTRAP_ADMIN_PASSWORD=强管理员密码
```

本地体验可以保持 `BLOCKCHAIN_ENABLED=false`。此时项目登记、交易和注销主流程均可使用，只是不创建链上任务。

生产环境使用找回密码功能时，还需配置 `FRONTEND_URL` 及 SMTP 相关环境变量。非生产环境未配置 SMTP 时，界面会显示一次性开发重置令牌，便于本地验收。

### 4.3 启动服务

```powershell
docker compose up --build -d
```

启动后访问：

- 管理控制台：`http://localhost:3000`
- API 健康检查：`http://localhost:8000/health/ready`
- API 交互文档：`http://localhost:8000/docs`

查看服务状态和日志：

```powershell
docker compose ps
docker compose logs --tail=100 api
```

停止服务：

```powershell
docker compose down
```

上述命令默认保留 PostgreSQL 数据卷。除非明确要清空所有业务数据，否则不要使用带 `-v` 的停止命令。

## 5. 首次登录与账号准备

1. 使用 `.env` 中的 `BOOTSTRAP_ADMIN_EMAIL` 和 `BOOTSTRAP_ADMIN_PASSWORD` 登录。
2. 初始管理员只会在该邮箱尚不存在时创建；后续修改环境变量不会自动重置已有账号密码。
3. 普通用户可在登录页单击“注册账号”完成自助注册，也可以在 API 文档中调用 `POST /api/v1/auth/register`：

```json
{
  "email": "member@example.com",
  "password": "MemberPass123!",
  "display_name": "示例企业"
}
```

4. 注册密码长度必须为 10～128 个字符，建议同时包含大小写字母、数字和符号。
5. 管理员登录后可进入“用户管理”，分配核证员/管理员角色或停用账号。

## 6. 控制台操作说明

### 6.1 登录与退出

1. 打开管理控制台。
2. 输入邮箱和密码，单击“登录控制台”。
3. 登录后右上角显示当前用户，左侧显示功能菜单。
4. 单击左下角用户信息旁的退出图标即可退出。

JWT 默认有效期为 30 分钟。令牌过期后需要重新登录。

### 6.2 查看运营总览

进入“总览”后，可以查看累计签发、累计注销、市场在售、累计成交、项目总数、最近项目和最新挂单。这里展示的是平台级汇总数据，不是仅针对当前用户的统计。

### 6.3 新建并提交项目

1. 进入“碳项目”。
2. 单击“新建项目”。
3. 填写项目名称、项目类型、地区、核证方法学、预计减排量和说明。
4. 单击“创建项目”，项目以“草稿”状态保存。
5. 在项目列表中找到该项目，单击“提交”。
6. 项目进入“待审核”状态，等待管理员或核证员处理。

注意：只有项目所有人可以提交该项目；已通过项目不能再次提交。草稿或已驳回项目可先编辑后重新提交，也可删除；待审核和已通过项目不能编辑或删除。

### 6.4 审核项目

适用角色：管理员、核证员。

1. 在“碳项目”页切换到“待审核”。
2. 找到目标项目，单击“审核”。
3. 选择“核证通过”或“驳回并要求补充材料”。
4. 填写审核意见并确认。

审核通过后项目变为“已通过”；驳回后变为“已驳回”。启用区块链配置时，审核通过还会创建项目登记链上任务。

### 6.5 签发碳额度

适用角色：管理员、核证员。

1. 在“碳项目”页筛选“已通过”。
2. 找到项目并单击“签发”。
3. 填写核证年份和签发数量。
4. 单击“确认签发”。

签发成功后，额度进入项目所有人的“我的资产”，并产生一条“额度签发”流水。同一项目和同一年份不能重复创建批次；如需追加签发，当前版本没有追加批次功能。

### 6.6 查看资产与流水

进入“我的资产”：

- “资产总量”包含可用和已锁定额度；
- “可用余额”可用于挂单或注销；
- “挂单锁定”表示已放入未完成卖单、暂时不能再次使用的额度；
- 单击批次短编号可以复制完整批次 ID；
- 右侧资产流水显示本账户余额的每次变化。

### 6.7 发布卖单

1. 进入“交易市场”。
2. 单击“发布挂单”。如果没有任何持仓，该按钮不可用。
3. 选择资产批次，确认界面显示的可用数量。
4. 输入出售数量和单价。
5. 单击“发布挂单”。

发布后，相应数量会被锁定，但仍计入资产总量。挂单货币当前固定为人民币 CNY。

### 6.8 购买碳额度

1. 在“交易市场”浏览挂单，或按批次编号搜索。
2. 找到其他用户的挂单，单击“立即购买”。
3. 输入购买数量，可以少于挂单剩余数量。
4. 确认单价和数量后，单击“确认并完成交易”。

交易成功后，额度立即从卖方持仓转入买方持仓，双方都会产生资产流水。系统当前只记录应付金额，不会实际划转人民币或调用支付机构。

### 6.9 撤销卖单

在“交易市场”找到自己的未完成挂单，单击“撤销”。未成交的剩余数量会立即解除锁定。已全部成交或已撤销的挂单不能再次撤销。

### 6.10 永久注销额度

1. 进入“注销管理”。
2. 单击“发起注销”。只有存在可用余额时该按钮才可用。
3. 选择资产批次，填写注销数量、受益方和注销用途。
4. 核对信息后，单击“确认永久注销”。
5. 保存系统返回的证书编号。

注销不可撤销。已被挂单锁定的额度不能注销，如需注销该部分额度，应先撤销相关挂单。

### 6.11 验证注销证书

1. 在“注销管理”的证书验证区输入完整证书编号，或直接打开无需登录的 `/verify` 页面。
2. 执行查询。
3. 系统显示数量、受益方、注销时间和证书编号。

也可以直接调用公开接口：

```text
GET /api/v1/retirements/{certificate_no}
```

### 6.12 查看链上存证

适用角色：管理员。

进入“链上存证”可查看当前网络、Chain ID、确认阈值、签名方式、合约地址、操作账户以及链上任务队列。任务会依次经历待处理、已签名、已广播、已确认或失败状态；Worker 自动广播并在达到配置确认数后回填区块号。

### 6.14 注册、用户管理与密码

- 登录页单击“注册账号”可创建企业用户；
- 管理员进入“用户管理”可修改名称、角色和启用状态；
- 登录用户进入“账号设置”可使用当前密码修改新密码；
- 登录页单击“忘记密码”，通过邮件链接或非生产环境显示的开发令牌完成重置。

### 6.13 查看审计日志

适用角色：管理员。

进入“审计日志”，可查看关键业务操作、操作者、资源类型、资源编号和操作时间。使用搜索框可按操作名称或资源编号过滤当前加载的最近记录。

## 7. 推荐的完整业务流程

### 7.1 项目签发流程

1. 企业用户新建项目并提交；
2. 核证员或管理员审核通过；
3. 核证员或管理员为项目签发指定年份的碳额度；
4. 项目所有人在“我的资产”确认持仓和签发流水。

### 7.2 市场交易流程

1. 卖方选择持仓批次发布挂单；
2. 系统锁定卖方相应额度；
3. 买方选择挂单和数量完成购买；
4. 系统原子更新双方余额、挂单状态、成交记录和流水；
5. 卖方可撤销未成交的剩余部分。

### 7.3 注销与核验流程

1. 额度持有人选择可用额度发起注销；
2. 填写受益方和用途并确认；
3. 系统扣减持仓并生成唯一证书；
4. 任何人可通过公开 API 使用证书编号核验记录。

## 8. 关键业务规则

- 额度数量最多保留 4 位小数，价格最多保留 2 位小数；
- 只有已通过的项目可以签发额度；
- 同一项目、同一核证年份只能签发一个批次；
- 可用余额 = 持仓总量 - 挂单锁定量；
- 挂单、购买和注销数量必须大于 0；
- 用户不能购买自己的挂单；
- 购买数量不能超过挂单剩余数量；
- 挂单或注销数量不能超过可用余额；
- 注销不可撤销；
- 签发、购买、注销 API 必须提供唯一的 `Idempotency-Key`；控制台会自动生成该值。

## 9. 运维检查与常见问题

### 9.1 页面无法打开

执行 `docker compose ps`，确认 `carbon-link-front`、`api` 和 `db` 均已启动。若 API 尚未健康，查看 `docker compose logs --tail=100 api`。

### 9.2 登录失败

- 确认邮箱和密码与 `.env` 一致；
- 注意修改 `.env` 不会重置已经创建的管理员；
- 确认数据库服务健康；
- 连续运行旧环境时，实际账号数据保存在 Docker 数据卷中。

### 9.3 端口被占用

在 `.env` 中修改：

```dotenv
FRONTEND_PORT=3001
API_PORT=8001
```

然后重新运行 `docker compose up -d --build`。容器内部端口和前端到 API 的代理关系不会改变。

### 9.4 无法发布挂单或注销

检查“我的资产”中的可用余额，而不是资产总量。已经挂单的额度处于锁定状态，不能再次挂单或注销。

### 9.5 找不到审核、签发、链上存证或审计菜单

这些功能受角色控制。审核和签发只对管理员、核证员开放；链上存证和审计日志只对管理员开放。

### 9.6 链上任务一直没有交易哈希

执行 `docker compose ps` 确认 `chain-worker` 正在运行，并查看 `docker compose logs --tail=100 chain-worker`。同时检查 RPC、合约地址、操作账户签名配置、合约角色和 gas 余额。Worker 会自动重试暂时性失败；达到最大次数后任务标记为失败并保留错误信息。

## 10. 当前限制与后续工作

- 交易只完成碳额度交割和成交金额记账，尚未接入法币支付；
- 项目仅在草稿或已驳回状态下允许编辑、删除；已进入审核或签发流程的数据不可直接改写；
- 同一项目和同一年份不支持追加签发；
- 生产环境密码找回依赖可用的 SMTP 服务；
- 当前链上采用平台操作账户托管模型，链上数量按 `1 tCO₂e = 10,000` 个基础单位换算；
- 区块链功能默认关闭；启用前需部署合约、授予操作账户角色，并安全配置本地密钥或外部签名服务；
- 生产环境应使用 HTTPS、外部密钥管理服务、数据库备份和恢复演练，不应直接暴露 PostgreSQL 或 API 端口。

更详细的服务器和合约部署步骤参见 [Ubuntu 部署指南](./DEPLOY_UBUNTU.md)，接口字段和在线调试以 `/docs` 中的 OpenAPI 页面为准。
